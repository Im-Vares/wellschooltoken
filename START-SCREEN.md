# Запуск приложения через start.sh в screen

## Быстрый старт

### 1. Подключитесь к серверу

```bash
ssh root@your-server-ip
```

### 2. Перейдите в директорию проекта

```bash
cd ~/wellschooltoken
# или
cd /var/www/wellschool-token
```

### 3. Создайте screen сессию

```bash
screen -S wellschool
```

### 4. Запустите приложение

```bash
./start.sh
```

### 5. Отключитесь от screen (не закрывая приложение)

Нажмите: `Ctrl+A`, затем `D` (detach)

### 6. Вернуться к screen сессии

```bash
screen -r wellschool
```

## Управление screen

- **Создать новую сессию**: `screen -S название`
- **Список сессий**: `screen -ls`
- **Подключиться к сессии**: `screen -r название`
- **Отключиться (detach)**: `Ctrl+A`, затем `D`
- **Закрыть сессию**: Внутри screen нажмите `Ctrl+A`, затем `K`, затем `Y`
- **Прокрутка**: `Ctrl+A`, затем `[`, используйте стрелки для прокрутки, `Q` для выхода

## Проверка работы

После запуска проверьте:

```bash
# В другом терминале или после detach
curl http://localhost:5001/api/health
curl http://localhost:3001
```

## Остановка приложения

```bash
# Подключитесь к screen
screen -r wellschool

# Остановите приложение (Ctrl+C)
# Или закройте screen сессию
```

## Автозапуск при перезагрузке сервера

Если нужно, чтобы приложение запускалось автоматически, используйте PM2 (см. deploy.sh) или создайте systemd service.

## Переменные окружения

Убедитесь, что файлы `.env` настроены:

- `backend/.env` - для backend
- `frontend/.env.local` - для frontend (создается автоматически)

## Порты

- **5001** - Backend API
- **3001** - Frontend (Next.js)

Если порты заняты, остановите процессы:

```bash
# Найти процессы на портах
sudo lsof -i :5001
sudo lsof -i :3001

# Остановить процессы
sudo kill -9 <PID>
```
