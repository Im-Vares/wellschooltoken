# Исправление ошибки 502 Bad Gateway

## Быстрое решение

Выполните на сервере:

```bash
cd ~/wellschooltoken
chmod +x deploy/fix-502.sh
sudo ./deploy/fix-502.sh
```

## Ручное исправление

### Шаг 1: Проверка статуса PM2

```bash
pm2 status
```

Если приложения не запущены или остановлены, запустите их:

```bash
cd /var/www/wellschool-token
pm2 start ecosystem.config.js
pm2 save
```

### Шаг 2: Проверка портов

```bash
# Проверка портов
sudo netstat -tlnp | grep -E '3001|5001|6385'

# Или
sudo lsof -i :3001
sudo lsof -i :5001
sudo lsof -i :6385
```

Если порты не заняты, приложения не запущены.

### Шаг 3: Проверка логов

```bash
# Логи PM2
pm2 logs --lines 50

# Логи Nginx
sudo tail -f /var/log/nginx/error.log
sudo tail -f /var/log/nginx/wellschool-token-error.log
```

### Шаг 4: Проверка конфигурации Nginx

```bash
# Проверка синтаксиса
sudo nginx -t

# Просмотр конфигурации
cat /etc/nginx/sites-available/wellschool-token
```

Убедитесь, что в конфигурации указаны правильные порты:
- `proxy_pass http://localhost:3001;` для frontend
- `proxy_pass http://localhost:5001;` для backend

### Шаг 5: Перезапуск всех сервисов

```bash
# Остановка
pm2 stop all
pm2 delete all

# Очистка портов (если нужно)
sudo lsof -ti:3001 | xargs kill -9 2>/dev/null || true
sudo lsof -ti:5001 | xargs kill -9 2>/dev/null || true

# Запуск
cd /var/www/wellschool-token
pm2 start ecosystem.config.js
pm2 save

# Перезагрузка Nginx
sudo systemctl reload nginx
```

### Шаг 6: Проверка доступности

```bash
# Проверка frontend
curl http://localhost:3001

# Проверка backend
curl http://localhost:5001/api/health

# Проверка через Nginx
curl http://localhost:6385
```

## Частые причины 502 Bad Gateway

1. **Приложения не запущены** - запустите через PM2
2. **Неправильные порты в Nginx** - проверьте конфигурацию
3. **Приложения упали** - проверьте логи PM2
4. **Проблемы с правами доступа** - проверьте права на файлы
5. **База данных не инициализирована** - запустите инициализацию

## Проверка ecosystem.config.js

Убедитесь, что файл существует и содержит правильные настройки:

```bash
cat /var/www/wellschool-token/ecosystem.config.js
```

Должны быть указаны:
- Frontend на порту 3001
- Backend на порту 5001
- Правильные пути к директориям

## Если ничего не помогает

1. Проверьте, что Node.js установлен: `node -v`
2. Проверьте, что зависимости установлены: `cd backend && npm list`
3. Проверьте логи ошибок: `pm2 logs --err`
4. Пересоздайте ecosystem.config.js из deploy.sh
